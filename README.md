# Personal Portfolio & Semantic Contact Form

This repository contains a responsive personal portfolio webpage built for **Experiment 3: Creating an HTML Form Using Semantic Elements**[cite: 2]. It serves as a professional landing page and includes a comprehensive "Connect With Me" form for networking and collaboration.

## Features
* **Semantic HTML Structure:** Utilizes standard HTML5 elements (`<header>`, `<nav>`, `<main>`, `<section>`) for improved accessibility and document structure.
* **Organized Form Fieldsets:** Groups related user input fields using `<fieldset>` and `<legend>` tags, covering Personal Details, Contact Information, Professional Details, Interests, and Contact Purpose[cite: 2].
* **Varied Input Types:** Implements multiple HTML input types including `text`, `email`, `tel`, `date`, `radio`, `checkbox`, `select`, and `textarea` to efficiently capture structured user data[cite: 2].
* **Clean CSS Styling:** Features a modern, responsive layout using native CSS for alignment, spacing, and hover states without relying on external frameworks[cite: 2].
